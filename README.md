#### Description:

I would like to create an app where I can import a CSV file from my bank, and the information will be saved in MongoDB.

This is my final project for the CS50 course as well as a personal project because I don’t want to manually enter all of my expenses into an Excel spreadsheet.

The goal of this project is to make tracking my expenses easier by allowing me to upload my bank's CSV file and have the transaction information automatically stored in a database. As I continue developing the project, I plan to add features that will make it easier to view, organize, and manage my expenses.
